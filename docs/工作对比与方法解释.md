# CTI-VLA 工作对比与方法解释

更新：2026-10-12。本文说明方法差别及研究理由；CTI-VLA 的收益尚待实验验证。

## 1 先把比较对象说清楚

我们和 VLA-ACL 都希望训练小选择器，在推理时真正删除视觉 token。主要区别在于：**怎样教小选择器判断该删谁。**

| 方法 | 训练时向模型提出的问题 |
|---|---|
| VLA-ACL | 怎样连续调节各 token 的信息，使输出动作保持正确？ |
| Action-JND | 一个 token 的特征最多能改变多少，而动作仍可接受？ |
| CTI-VLA | 当前已经只剩这些 token，再实际删除其中一个，动作偏差会增加多少？ |

来源：[VLA-ACL](https://arxiv.org/html/2610.08133v2)、[Action-JND](https://arxiv.org/html/2608.21247v2)。这些差别提供研究切入点，本身还不等于性能优势。

## 2 软门控是什么

**软门控给每个 token 一个连续的“信息保留程度”。** 接近 1 时保留原特征，接近 0 时更多地用参考特征替代。token 仍占据输入序列的位置。

硬删除则直接把某些项拿出序列。以四个 token 为例：

- 软门控后：仍有四项，只是其中两项的信息被明显弱化或替换。
- 硬删除后：只剩两项，后续主干只处理这两项。

这里改变的是特征向量，不是给原图调亮度。

VLA-ACL 的具体操作为：

\[
\tilde z_i=s_i z_i+\sqrt{1-s_i^2}\,b_i,\qquad \sum_i s_i=k,
\]

其中 b_i 来自黑色图像的编码。训练时序列仍保留所有位置，推理时改用硬 Top-k，删除未入选项。[论文 III-B](https://arxiv.org/html/2610.08133v2#S3.SS2)

## 3 为什么训练时使用软门控

假设两个分数为 0.8 和 0.6，Top-1 选第一个。把 0.8 改成 0.79，选中的 token 不变，后面的动作也可能完全不变。对这种离散选择，普通梯度难以告诉打分器“分数应该怎样微调”。

连续门控允许分数的小变化影响输入特征，动作误差便可以反向传回打分器。VLA-ACL 用这条路径学习选择规则。

**冻结 VLA 参数，不等于阻断经过 VLA 的梯度。** 它可以不更新大模型权重，仍计算动作损失对输入门控的梯度。CTI-VLA 则先生成离散删除标签，再直接监督小网络，避开这条反传路径。

## 4 CTI-VLA 怎样训练

分成两个独立阶段：

1. **教师标注：**冻结 VLA，计算完整输入动作作为参照；对某个保留集合 S 实际删除 token i，记录动作误差增加了多少。
2. **小网络学习：**用记录的数值监督选择器。输入包含 token、指令、proprio 和当前保留集合摘要，梯度只更新小网络。

例如，某集合相对完整教师的动作误差为 0.02，删掉 i 后变为 0.09，则该样本标签为 0.07；若删后降为 0.01，标签为 -0.01。这里的数值仅用于说明定义，并非实验结果。

推理时不用教师反复试删，而由小网络预测上述代价。每轮固定保留数量，用 Top-k 留下预测删除代价较高的 token；更新集合后再评分，最后执行一次稀疏 VLA 前向。

## 5 改进的理由是什么

**理由一：训练监督对应实际部署操作。**

改变一个仍在序列里的向量，与把它从序列中移除，会产生不同的注意力计算。因此，我们直接测真实删除，减少从“特征变化”推断“删除效果”的一层近似。

这是需要检验的优势：软门控提供了容易优化的训练路径，可能已经足够有效；不能预设真实删除标签必然更好。

**理由二：重要性可能随保留集合变化。**

假设两个相机都看见杯子。两份信息都在时，删除任意一份可能影响很小；第一份已删除后，第二份可能变得关键。这说明“在完整输入中不重要”不等于“在当前稀疏输入中不重要”。

CTI-VLA 显式标注不同集合下的删除代价，并在剪枝过程中更新分数。这个例子解释研究动机，不证明现有方法无法学习冗余关系。

**理由三：可以把大模型标注与小模型训练分开。**

缓存无梯度教师结果后，训练选择器不需要保留大 VLA 的反向传播激活，可能降低训练显存压力。但教师需要多次前向，标签生成可能更慢；多轮选择也有开销。是否更省总成本，要一起测量。

## 6 怎样证明这项改进成立

| 对照 | 检验内容 |
|---|---|
| 软门控动作监督 vs 真实删除标签监督 | 与部署一致的监督是否改善实际删除后的表现 |
| 完整上下文单次删除标签 vs 集合条件标签 | 显式考虑已保留信息是否有额外价值 |
| 一轮 Top-k vs 分阶段重新评分 | 集合更新的收益能否覆盖额外计算 |

VLA-ACL 的联合动作损失可以隐式学习 token 依赖；CTI-VLA 的批量删除也可能在同一轮误删互相替代的信息。我们的主张只是：**显式、与实际删除一致的集合条件监督，值得作为一种替代训练方式检验。**

只有在匹配条件下改善闭环成功率与延迟，或以更低的完整训练成本达到相近表现，才能把方法差别写成有证据的改进。
