### 研究目标与 WAM 的关系

研究目标仍是：在固定视觉 token 预算下，保留控制与未来任务状态所需的信息，改善冻结 VLA 的成功率—完整延迟折中。暂不另立任务变化鲁棒性问题，也不以“真实删除训练不同于 ACL”作为贡献。

未来预测辅助监督借鉴世界模型学习，但当前提案的优化对象是剪枝选择器，原 VLA 策略权重全部冻结。训练期增加轻量未来预测头，部署时移除该头；不训练完整视频生成模型、不微调大策略、不在线想象未来。注意：仅在推理时去掉未来生成并不能区分 WAM；[Fast-WAM](https://arxiv.org/abs/2603.16666) 本身采用了这种设计。我们的方法归属应由冻结策略下的 token 选择目标和实际实现说明。

### 三项修改

1. **软门控联合训练。** 以 ACL 的 soft Top-k 和参考特征门控为起点，连续调节视觉 token；用动作一致性训练 DIE 和条件编码模块。完整教师无梯度，软门控分支允许梯度经过冻结 VLA 回到选择器，VLA 参数不更新。旧版“训练只读 detached 标签、不反传经过 VLA”的方法约束不适用于此修订。
2. **加入未来辅助监督。** 训练期轻量预测头读取门控后的视觉信息、指令/当前 proprio，以及轨迹中实际执行的动作，预测同轨迹对应时刻的未来状态表征。目标从真实未来观测提取并停止梯度。不能拿剪枝策略生成的新动作去匹配原示范的未来，冒充该动作的物理后果。
3. **轻量部署。** DIE 只读取当前可用输入，执行一次硬 Top-k 和统一 packing，再运行一次冻结 VLA。未来帧、示范后续动作、未来预测头均不进入部署。原单 token 删除标签降为诊断；分阶段集合重评分暂缓，不是首轮必需模块。

训练目标记为：

\[
L = L_{\mathrm{ACL}} + \lambda L_{\mathrm{future}}.
\]

其中 L_ACL 沿用教师动作一致性及真实动作辅助监督；L_future 是未来表征预测误差。预测头仅在训练中更新，未来目标编码器冻结。λ、未来表征定义、预测跨度及头结构尚待小规模开发后预登记，不视为已经冻结的配置。

**未来监督的语义边界：**预测未来 8 步动作仍是动作监督；预测随后真实观测的表征才属于本节的未来状态监督。后者检验所选信息的预测价值，不自动证明删除 token 会因果地改变未来环境或提高成功率。

### 候选补强及优先级

- 优先研究任务相关的未来状态/变化表征，避免整帧预测被静态背景主导。[World Guidance](https://proceedings.mlr.press/v306/su26c.html) 与 [Token-World](https://arxiv.org/abs/2610.00575) 提供紧凑、面向控制的未来表征参考，但没有直接证明其用于本项目剪枝的收益。
- 首轮可使用冻结编码器提取的未来视觉特征作为明确的起点；它只是通用未来表征，不能预称“任务相关”。任务相关表征的取得方式和额外监督成本须单独定义后才能加入。
- 集合条件下的未来信息贡献保留为后续候选。先建立未来监督的增量，再判断是否需要多轮重评分；不同时扩展多时域、critic、在线 RL 或自由动态预算。

### 下一轮 G1 的最小对照

主预算固定为两视角总计 128（每相机 64）；用同一 DIE、条件、样本池、训练步数、有效 batch、门控和部署 packing 比较：

| 版本 | 训练监督 | 部署 |
|---|---|---|
| M0，matched ACL | 仅动作监督 | 当前输入 → DIE → 硬 Top-k → 冻结 VLA |
| M1，未来辅助版 | 相同动作监督 + 未来预测监督 | 与 M0 相同，未来头移除 |

先验收梯度、未来时刻对齐和硬剪枝，再做验证集及已有独立开发初态上的配对闭环；不以未来预测误差降低单独判定成功。未来分支的特征提取、缓存、预测头训练和反传都计入成本，另报告相同计算预算下的对照。若 M1 出现可靠的闭环增量，再扩训练 seed、64-token 预算和集合条件候选；若无增量，不扩大新模块或逐 token 标注。

未来采样必须在原 episode 划分内重建有效窗口：当前帧、真实动作区间和未来帧属于同一 episode/split；末帧或不足预测跨度的窗口按预登记规则排除并报告数量。原首/中/末 906/189/198 个观测不能直接视为相同数量的有效未来训练样本。

原生 ACL 仍作为独立强基线，M0 只能称 matched ACL。G1 v1 的真实边际选择及小步长诊断未通过继续条件，不据此宣布新方案已通过；新 G1-F 需要独立配置和运行记录，详见 [完整实验计划当前修订](完整实验计划.md#当前修订v11未来辅助剪枝2026-10-14)。

## v1 原始方案归档（2026-10-12，不再作为当前执行指令）

**题目：CTI-VLA: Counterfactual Token Influence for Efficient Vision-Language-Action Policies**

更新：2026-10-12。独立项目根目录：F:/CTI-VLA。定位：冻结 VLA 的视觉 token 剪枝。以下为研究方案，实验收益尚待验证。

**训练属性：需要训练，但仅训练轻量选择器与条件编码模块；VLA 全部冻结，教师无梯度生成标签。剪枝对象仅为视觉 token。推理每轮固定数量，用 Top-k 决定保留哪些 token。**

术语及对比的通俗解释见：[工作对比与方法解释](F:/CTI-VLA/docs/工作对比与方法解释.md)。

## 摘要

视觉语言动作模型的视觉 token 剪枝需要在推理效率与控制性能之间取得平衡。一个关键问题是：token 的决策价值可能随任务指令、本体状态和其他 token 的保留情况而变化；完整上下文中的单 token 影响，未必能指导高比例的联合删除。为此，我们提出 CTI-VLA，一种基于条件反事实影响的视觉 token 剪枝框架。该框架冻结 VLA，在不同保留集合上执行与部署一致的真实 token 删除，以删除前后相对于完整策略的动作偏差增量构造监督，训练结合任务条件与集合信息的轻量影响估计器。推理时，估计器分阶段更新保留集合，最终将稀疏视觉前缀送入 VLA，仅执行一次策略前向。与软门控动作一致性蒸馏及特征扰动容忍度学习相比，本研究聚焦实际删除操作下的集合条件影响。我们将在 LIBERO 上检验该监督是否改善高压缩下的 token 选择，并联合评估闭环成功率、端到端延迟及标注训练总成本。

## 1 研究问题

**核心问题：在固定 token 预算下，显式学习当前保留集合中的删除影响，能否比单 token 归因和直接动作一致性蒸馏，更好地保留控制所需信息？**

需要检验三个假设：

1. **任务条件有用：**同一画面在不同指令或本体状态下，需要保留的信息可能不同。
2. **集合条件有用：**单独删除影响小的 token，联合删除时可能因冗余或协同产生较大动作偏差。
3. **干预一致性有用：**真实删除的监督，可能比全长 token 替换更适合指导 packed 推理。

目标是保持冻结策略的动作行为，并验证闭环控制表现；不将动作偏差称为环境回报 regret，不承诺成功率保证。

### 与已有工作的区别及拟验证创新

“软门控”是在训练时连续调节 token 特征，保留序列位置，以便动作误差能反传到选择器；VLA-ACL 在推理时才真正删除 token。CTI-VLA 则在标注时就执行真实删除，把得到的代价作为标签教给小网络。两者都能做硬剪枝，区别主要在学习选择规则的方式。

| 对比对象 | 已有工作 | CTI-VLA 拟验证的增量 |
|---|---|---|
| [VLA-ACL](https://arxiv.org/html/2610.08133v2) | 用软门控后的动作一致性训练 scorer，梯度穿过冻结 VLA | 用真实硬删除的条件边际标签训练 scorer；随保留集合更新评分，训练不反传大主干 |
| [Action-JND](https://arxiv.org/html/2608.21247v2) | 学习保持动作响应的特征扰动容忍度，指导压缩 | 直接估计特定保留集合中实际删除 token 的误差增量 |
| DIWA 历史原型 | 完整上下文中的单 token 均值替换，视觉特征打分 | 作为历史对照；CTI-VLA 独立实现任务条件、集合标签与统一 packing |

**核心创新候选是“与部署一致的集合条件删除监督”，而非冻结教师、小打分器或动作一致性本身。** VLA-ACL 的联合软门训练也能隐式学习 token 依赖，不能将其描述为完全忽略交互。离线摊销归因已有 [FastSHAP](https://arxiv.org/abs/2107.07436) 等先例；低显存与低总成本也必须分别实测。

## 2 方法设计

### 2.1 固定基座与目标

使用 OpenVLA-OFT：双视角、512 个视觉 token、proprio、确定性 L1 action head，输出归一化的 8×7 动作。视觉编码器、projector、语言主干和动作头全部冻结，仅训练轻量估计器及其条件编码模块。

记 c 为语言指令与归一化 proprio，S 为保留的视觉 token 集合：

\[
a_{\mathrm{full}}=F(Z,c),\qquad
a_S=F(\operatorname{Pack}(Z_S),c),\qquad
E(S)=\frac{\|a_S-a_{\mathrm{full}}\|_1}{8\times7}.
\]

固定预算 k 时，希望选择大小为 k、使 E(S) 较小的集合。E 衡量动作保持程度，闭环成功率另行评测。

### 2.2 真实删除的条件监督

对 i∈S，定义：

\[
y_i(S,c)=E(S\setminus\{i\})-E(S).
\]

正值表示删除后动作偏差增加，负值表示删除后更接近完整教师。**标签允许为负，使用线性输出，不施加 softplus 非负约束。**

标注流程：

1. 每个观测缓存完整教师动作和视觉特征。
2. 从保留数 512、256、128 的集合中采样；非完整集合混合使用随机、均匀和当前 selector 产生的集合。
3. 每个集合先计算 E(S)，再采样少量 token 实际删除，得到标签。初始每状态取 2 个集合、每集合标注 8 个 token，最多约 19 次策略前向；避免逐状态穷举 512 个 token。
4. 缓存具体集合、token 索引、指令/proprio、模型与位置规则版本。初版训练后，补标一批实际 selector 路径上的集合，减少训练与推理的集合分布偏移。

教师全程 eval 与无梯度前向。相机内均值替换仅保留作对照。

### 2.3 轻量影响估计器

\[
\hat y_i=g_\phi\big(u_i,\ e_\ell,\ e_p,\ h_S,\ |S|/512\big).
\]

- u_i：投影到 256 维的视觉特征及相机、原 patch 位置编码。
- e_\ell：冻结词嵌入经过轻量带位置编码的指令编码模块；同一指令可缓存，不调用完整语言主干。
- e_p：归一化 proprio 的小 MLP 编码。
- h_S：当前保留 token 的分视角集合摘要；初版采用均值与最大值池化。
- g：两层小 MLP，预测条件删除增量；估计器同时读取 token 内容、任务条件与集合信息。

首版采用 **Huber 回归**，同一集合内的 pairwise ranking loss 作为可选消融。标签用训练集拟合的统一尺度归一化，不做逐样本 max-normalization。训练只访问 detached 缓存；不额外引入世界模型、critic 或大主干微调。

### 2.4 推理与统一 packing

从完整集合开始，用小估计器删除预测增量较小的 token，更新集合摘要并重新评分：

**512 → 256 → 128 → 64，到目标预算即停止；最终只运行一次 VLA。**

初版每相机保留一半预算，便于匹配对照。训练标签覆盖这些阶段；多轮的小网络开销全部计入推理延迟。

标注、验证、部署和 profiler 共用同一 packing：选中 token 按原序列顺序排列，保留完整序列中的原位置编号，按缩短后的长度重建 attention mask 与 action slice；语言、proprio 和动作位置规则一致。

这是**分阶段批量删除的近似策略**。同一轮内仍可能同时删掉互相替代的 token，不能声称消除了所有交互或达到最优集合。若小规模集合搜索有收益而该策略没有，先检查批量删除步长及集合摘要能力。

## 3 实验设计

### 3.1 数据与对照

- **数据：**先用 LIBERO Spatial 开发，按 episode 分离训练、验证和最终测试，覆盖轨迹早、中、晚阶段。DIWA 的 120 个早期观测属于历史 pilot，不计作 CTI-VLA 新实验。
- **扩展：**核心结果成立后，再测试 Goal 或 Long，并使用对应 suite 的基座。第一阶段无需 RoboTwin 或真实机械臂。
- **预算：**两视角合计保留 256、128、64 个 token，完整 512-token 策略作参考。
- **对照：**dense、分视角均匀/随机、原 LOO-DIE、VLA-ACL，以及一个可复现的免训练强基线，如 [SpecPrune-VLA](https://proceedings.mlr.press/v306/wang26jj.html)。Action-JND 是主要机制近邻；若实现与权重可用，纳入直接比较。
- **公平性：**统一 checkpoint、预处理、动作 chunk、评测初始状态和计时边界；基线保留原生算法，另做位置规则、视角预算匹配的受控对照，报告完整标注训练成本。

### 3.2 先判断核心假设，再扩大训练

| 阶段 | 实验 | 回答的问题 |
|---|---|---|
| 小规模诊断 | 50–100 个完整轨迹阶段的状态；比较同集合的替换与删除、同 token 在不同集合的影响、合理的同图不同任务条件 | 三个问题是否实质影响选择质量？ |
| 选择收益测试 | 极小子集用真实 y 执行相同三轮删除，对比 LOO top-k、均匀选择和 ACL；必要时补逐步集合搜索 | 教师边际排序本身是否有效？搜索结果不称全局最优 oracle |
| 轻量训练 | 先 500–1000 个观测，按有限候选预算生成标签，训练单个 DIE | 条件标签能否转化为可部署选择能力？ |
| 闭环验证 | 诊断阶段即跑 dense、均匀和现有 DIE 的小冒烟；新方法先在 2–3 个任务做 pilot，再扩整个 suite | 离线动作改善能否转化为控制收益？ |

小 pilot 用于排错与选型，不支持 1–2 个百分点的成功率结论。正式评估采用配对初始状态、多个训练 seed，报告逐任务结果与置信区间。

### 3.3 最小必要消融与指标

| 消融 | 隔离的因素 |
|---|---|
| 分别去掉语言、proprio，及保留完整条件 | 哪一种任务信息提供增量 |
| 完整上下文 LOO vs 集合条件标签 | 集合条件监督是否有增量 |
| 同样集合下均值替换 vs 真实删除标签 | 干预与部署一致性是否重要 |
| 一次选择 vs 分阶段更新 | 多轮选择的收益是否值得额外开销 |

消融尽量固定 scorer 容量、数据量和教师查询预算；同时记录实际 GPU 时，避免把额外标注或计算量误当方法收益。与 ACL 比较时，补充共享 scorer 容量与任务条件输入的监督方式对照。

**主要指标：**闭环成功率与 observation-to-action 延迟的 Pareto 曲线；延迟包含预处理/传输、视觉编码、打分、packing 和策略前向，报告中位数与 p95。

**辅助指标：**packed 集合动作误差 E(S) 的均值与尾部、关键阶段失败类型、峰值显存、教师查询数和“标注＋缓存＋训练”总 GPU 时。Spearman 和候选 coverage 仅用于诊断。

### 3.4 继续投入的依据

先看到条件删除标签改善真实 packed 集合质量，再扩大闭环实验。若真实教师边际执行相同三轮选择也无优势，先修改删除目标或步长，不扩大 DIE。论文需要建立：**集合交互造成实际失败 → 条件监督改善选择 → 改善体现为控制与效率收益**。

若只提高离线排序，或效果与 ACL 接近而总成本更高，就不继续按原主张扩张。若有效，贡献聚焦上述机制与证据，不追加未经验证的世界模型、因果识别或泛化保证。

**实施顺序：登记服务器权重与可复用历史缓存 → 在独立项目实现统一 packing 和条件输入 → 小规模判别实验 → 有限预算标注与训练 → 闭环及端到端评测。**
