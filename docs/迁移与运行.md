## 研究主线与当前边界

研究的问题是：固定视觉 token 预算时，当前保留集合中的真实删除误差增量，是否比完整上下文单 token 归因或软门控训练更适合控制任务。标签为 `E(S-i)-E(S)`，允许负值。推理只运行小网络的分阶段选择和最后一次 VLA。

首轮实验应先验证真实教师边际选择本身是否改善 packed 动作保持，再投入大规模标注。需要以闭环成功率、完整 observation-to-action 延迟和标注加训练总成本支持论文结论。当前工程测试只验证实现契约，不提供这些结论。

迁移范围与来源哈希分别见 [模型审计](迁移审计_packing.md)、[数据审计](迁移审计_data.md)、[方法审计](迁移审计_method.md)。旧 RoboTwin、世界模型、非负替换教师和早期120观测缓存没有成为当前方法依赖。

## 迁移时的后续顺序（当前门槛见完整计划）

1. 固定完整 rollout 预处理并跑 dense/均匀选择闭环基线。
2. 用50至100个覆盖完整阶段的观测，检查同集合的替换与删除、不同集合下同token影响及任务条件。
3. 若真实教师边际选择有收益，再补集合采样和完整标注调度，训练500至1000观测的选择器。
4. 最后做匹配条件的 ACL 等基线、多seed闭环与端到端延迟和总成本评测。
