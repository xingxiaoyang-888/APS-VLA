# 正式固定案例离线接口

`scripts/extract_formal_cases.py` 只实现正式规划已登记的诊断交付。它不运行策略、不读权重或封存状态值、不重跑评测，不增加研究配置或GPU预算。当前没有真实最终案例；CPU合成测试不代表研究结果。

```powershell
python -B scripts/extract_formal_cases.py --inputs results/formal_main_v2/cases_inputs/<已登记输入>.json --output results/formal_main_v2/cases/<全新目录>
```

输入JSON的`schema`为`formal_main_v2`，`kind`为`formal_fixed_case_inputs`。以下每个引用均是项目相对`path`和原字节`sha256`：

- `registration`：`configs/experiments/formal_main_v2.json`。
- `source_inventory`：已冻结173文件清单`results/formal_main_v2/source/formal_main_v2_run_564be0995e.json`。
- `supervisor_state`：本次审计的监督状态快照，含全部相关已登记终态及费用；不修改真实状态。
- `global_freeze`、`root_release`：同一冻结目录中的`global_freeze.json`和`root_release.json`。
- `final_reviews`：四个suite各自最新、完整的`root_downstream_review`引用；必须覆盖每suite的400初态×22方法。续跑历史由原审计链验证，不输入旧的不完整review作为最终结果。

本轮root明确采用每suite一个全22方法的持久final运行，工程分段沿同一ledger恢复；本案例接口据此仅接受每suite一份最新完整review。E04通用接口本身允许方法子集，但本入口拒绝多run/分批输入，不自动合并。CLI的输入文件及输出目录可使用项目内绝对路径，JSON内部证据引用统一使用正斜杠的项目相对路径。

入口先复核173源码、72选择器＋16参考与四套件开发完成的global freeze，再检查root release，之后才跟随最终索引和trial引用。复用原E04 `require_root_review`检查终态回存SHA；再次调用既有root审计producer的只读函数，重建wrapper/adapter、全部原始trial、报告及失败/重试成本，与原root收据核对。不会发布新的root通过收据。最终索引只含task/index/初态哈希；final运行目录的状态值`panel.json`不读取。

任何缺失或科学未完成返回`status=pending`（CLI退出2），不创建案例目录。SHA、身份、release或原始结构错误直接拒绝，不能变成“类别缺失”。只有35200个正式终态齐全后，才发布36组×4类共144个固定位置。

每suite/预算/seed，按数值`task_id`、`source_state_index`排序，选择B独有成功、A独有成功、共同失败、共同成功各首例。类别确实不存在记`missing`。`policy_error`是失败终态并明确标注；基础设施失败及未闭合尝试只保留成本，不作成败案例。

选择先于token诊断。只比较首个`control_step=0`且观测SHA相同的A/B chunk；不向后寻找匹配观测。首例无chunk或局部诊断不可用时保留首例、标为`unavailable`，不替换。若缺陷本身破坏原root证据验收，则整批拒绝，不以诊断降级掩盖损坏。后续轨迹可能随动作分歧，不能当作同输入mask比较。

输出为`cases.json`、`cases.md`、可用案例的双视角16×16位置网格`grids/*.svg`及最后发布的`case_receipt.json`。索引0–255为agentview，256–511为wrist；相机内索引的行/列为`index//16`、`index%16`。网格显示共同、A独有、B独有位置，报告交集/预算与Jaccard。无RGB、视频或虚构图像背景；不可用token不画成全空mask。

每例保存A/B trial、checkpoint身份、实际结果job、run/release/root-review引用，以及原JSONL文件SHA、1起始行号、字节位置/长度和包含原LF的行SHA。可用时报告相同观测上归一化动作chunk的A/B平均绝对差；它不是teacher/demo动作误差，也不是延迟。原Slurm成本仅引用且保留，不把此CPU提取计为新的GPU实验。

本入口不提供案例级teacher/demo动作误差；正式动作误差见既有选中checkpoint、共同validation面板的独立诊断表，不将其移植为某个final案例的误差。

目录必须全新；已有目录及中断半成品不覆盖。收据绑定输入、所有读到的证据、实际审计依赖源码和输出SHA。合成模式要求输入`synthetic=true`、`--synthetic`及名称以`synthetic`开头的新目录，JSON/Markdown/SVG显著标记`SYNTHETIC — NOT EXPERIMENTAL RESULTS`；没有跳过科学闸门的合成开关。
