# G1R 锚定候选诊断草案

2026-10-14，v0。**仅方案审阅完成，未激活、未选新样本、未运行。原 G1 no-go 与 G2/G3 停止决定不变。** 本草案细化 [候选二](G1后续方法候选.md)，不修改原实验计划或项目方法规范。

已有结果未支持按当前大步长直接用单点边际进行集合选择；小步长未稳定修复，均匀加随机的候选池质量也不足。新的问题是：**在较好的静态教师集合附近，有限的整组交换是否产生足够多的严格改善，单点边际能否识别它们？** 这是候选覆盖与加性近似诊断，不是新选择器的性能实验。

## 固定候选

沿用 [主 G1 配置](../results/g1_20261014_v1/config.json) 已验收的模型、输入、双相机顺序、原位置编号和真实 packing；执行时逐项绑定版本和哈希。误差仍为相对同一完整教师的归一化 8×7 动作块平均 L1。

1. 对完整 512 token 做实际逐 token 删除，按标签降序、原索引升序排列每相机 256 个 token。取每相机前 128 得上级集合 P256，前 64 得临时锚点 A128。
2. 固定生成三个双相机联合候选 C1–C3。每相机从零基排名 `rank[48:64]` 无放回抽 4 个移出，从 `rank[64:80]` 无放回抽 4 个补入。每个候选共移出 8、补入 8，最后两相机各 64、共 128 token；不分别挑选两个相机的最优结果再拼接。
3. 三个候选种子为 1701、2301、4101；逐观测/相机随机流由固定命名空间、sample ID、候选种子、相机编号派生，具体 RNG 实现与版本必须在执行前冻结。候选依据排名和固定随机流产生，不读取候选真实 E 后重采。重复候选保留编号、共享查询，不补抽。
4. A 只是临时候选，尚未作为已提交的当前集合；A 与三个 C 均属于 P256。因此可研究 `512→P256→选中的128` 路径。若先提交 A 再补回外部 token，就不再是原规则的严格嵌套删除。本草案不包含 64-token 继承规则，也不宣称完整部署路径已实现。

最终所有集合按原索引 gather。补入来自同一观测的完整 detached 特征，不用填充值或跨帧特征。

## 对照与标签

| 对照 | 定义与解释 |
|---|---|
| 静态锚点 | E(A)，也是静态完整集合 LOO 教师在主预算的结果 |
| 候选池事后最佳 | `min(E(A), E(C1), E(C2), E(C3))`；含 A，故不更差是构造保证 |
| 当前集合边际代理 | 在 A 上查询所有实际涉及的单移出/补入动作；按下式选 A 或候选，再报告它真正的 E |
| 完整集合线性代理 | 用完整集合 LOO 标签计算交换增量；因 A 是前64，必选 A（平局优先A），只作构造检查 |
| 均匀及随机 | 沿用原 uniform 与 random17/23/41 的最终128规则，单列；不临时加入事后最佳池 |

```text
d_remove(i) = E(A without i) - E(A)       # 实际127 token
d_add(j)    = E(A union j) - E(A)         # 实际129 token
pred_delta(C) = sum(d_remove) + sum(d_add)
true_delta(C) = E(C) - E(A)              # 实际128 token，允许负值
full_linear_delta(C) = sum(y_full_removed) - sum(y_full_added)
```

当前集合代理同时比较 A 的预测增量 0 与三个候选；不截负值、不取绝对值、不翻转 d_add 的符号。完整集合代理单独按上式计算，不能混用两者符号。平局顺序为 A、C1、C2、C3。保存每个真实/预测增量、代理所选集合及相对事后最佳的误差差距。三候选共用 A，不能将查询顺序当成逐步更新；另报三个实际候选及代理的退化案例、任务/阶段、夹爪和 chunk 分解，不能只报恒不劣的池内最佳。

## 新面板与有界成本

拟用原 4 个教师任务，各抽 3 条未进入原 90 观测面板的 train episode，每条早/中/晚，共 12 episodes、36 观测。候选 episode 按内容 ID 排序，各任务使用独立命名随机流，面板 seed=1231。此处只指定抽样规则，尚未生成 ID 清单；执行前须冻结实际清单、排除项及内容签名。validation/test 均不使用。这是新的 train 开发面板，不是泛化测试。

阶段沿用已冻结 train manifest 的样本：首帧0、中帧 `num_steps // 2`、末帧 `num_steps - 1`。不更换取帧定义；late 仍与末帧重合，不能当作独立语义阶段。

只查询三个候选实际涉及的 token，单移出与补入并集最多 48 次；不查询整个边界池的全部64次。

```text
每观测新唯一查询上界 = 1完整参考 + 512完整集合删除
                    + 1锚点 + 3整组候选 + 4均匀/随机对照
                    + 48锚点单点边际 = 569
36观测上界 = 20,484
```

另外预选每阶段一个观测（各阶段 `str(sample_id)` 字典序排序后首个），对完整参考、A、C1 各做一次独立重复，共 9 次；正常首次完整运行含复查的成功前向上界为 **20,493**，不含失败重试或中断后重算。每观测累计尝试上限 **600**，总上限 **21,600**，失败和完成状态未知的调用均占上限。缺少任何必需动作就标记不完整，不在成功候选中选择性取最优。记录成功查询、去重命中、重试和所有硬件占用；暂不承诺 GPU 小时。

## 预拟筛查规则

以下数值是尚未执行的资源分配规则，不是统计显著性标准。执行前必须随配置冻结，不能查新动作后调整。

- 数值复查最大动作绝对差超过 0.002，或非零差异无法解释时，先停查实现。令 ε 为 `max(1e-4, 5×复查中 E 的最大绝对差)`；差异取3个复查观测的 A、C1 原始/重复 E，分别使用对应的原始/重复完整参考。完整参考相对自身的 E 恒为0，不用于估计 ε。该 ε 只是有限复查容差，不是全36观测的噪声上界。
- 定义绝对改善 `gain=E(A)-min(E(A),E(C1),E(C2),E(C3))`。所有36观测均保留；只在总体 `mean(gain)/mean(E(A))≥5%` 且非末帧24观测同样≥5%时考虑继续。相应分母为0时不判通过。
- 至少8/12条 episode 的平均绝对 gain 大于ε，至少3/4任务及早中晚各阶段的平均绝对 gain 大于ε。均值按 episode/任务等权；报告所有零改善、最差案例及按 episode 聚类的区间。因含 A，非劣性及区间本身不证明方法有效。
- 未满足则停止此候选规则，不在已看结果的面板上换窗口、交换数或增加候选。满足也只说明候选池值得进一步研究，**不能开放旧 G2/G3**。

## 学习与部署仍需另外验证

本诊断的锚点和边际代理依赖昂贵真实教师查询，不能出现在低延迟部署中。若候选覆盖值得继续，下一版需单独冻结轻量静态生成器、候选规则、集合评分器、训练预算和独立 episode 评测；比较学习模型实际生成和选中的集合，不能用教师候选替代。若简单边际代理已经找到相同改善，应优先研究更简单的方案，而非预设必须增加集合评分头。

当前尚缺可执行 runner、候选 RNG/manifest 实现及测试、预期输入与 packing 对齐审计、成本和失败恢复验证。完成这些并形成独立科学审阅收据之前，本草案不产生任何新作业。两路设计审查由 packing_migration 与 data_migration 完成；root 仅整合为可审阅草案，未更改 G1 gate。
