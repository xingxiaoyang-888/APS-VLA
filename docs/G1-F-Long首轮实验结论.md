# LIBERO-Long G1-F 首轮实验结论

2026-10-15。状态：**首轮完成，停止自动扩展，test 保持封存。**

固定的 30 个开发初态上，B 为 27/30，A 为 26/30，完整模型为 29/30。B 净增 1 个成功初态，但离线动作误差略差；目前只有微弱正向点估计，尚不足以确认稳定的未来监督收益。也不能据此证明此前 Spatial 的结果受任务难度限制。

## 设置与验收

完整预登记见 [首轮执行登记](G1-F-Long首轮执行登记.md) 和 [配置](../configs/experiments/g1_future_long_v1.json)。本轮使用 Long 专属 OpenVLA-OFT 基座（`libero-10@95220f9`）与 Long RLDS（`6ce6aaaa/libero_10_no_noops`），重新初始化 DIE；没有复用 Spatial 选择器，也没有搜索超参数。

| 项目 | 实际执行 |
|---|---|
| 核心对照 | A：0.5×完整教师动作 L1＋0.5×示范动作 L1；B：相同 A＋0.1×未来视觉表征 MSE |
| 训练 | seed17；各 100 次更新、有效 batch8、800 次训练样本使用；90 train / 60 validation 窗口 |
| 匹配条件 | DIE 初始参数哈希、数据顺序、优化器、门控、验证频率与选模规则相同；只增加未来监督及训练期预测头 |
| 冻结与部署 | VLA 全部参数冻结，训练梯度经过 VLA 到 DIE；部署每视角64、共128 tokens，一次硬 Top-k、统一 packing、一次 VLA 前向；移除未来头 |
| 未来目标 | 同轨迹 `obs[t] + executed_actions[t:t+8] → obs[t+8]`；冻结视觉投影特征分区池化、固定随机投影和 LayerNorm，得到512维目标；预测头568→256→512 |
| 选模 | update 0/25/50/75/100 的真实硬剪枝验证 teacher L1 最低值；两组均选中 update100 |
| 评测 | 结果前冻结任务0/3/5，各10开发初态，dense/A/B共90条；环境seed0、运行seed17、等待10步、chunk8、官方Long上限520控制步 |

工程检查通过：174项相关 CPU 测试；Long 官方输入与共享 dense 链路在3个训练观测上误差为0；F01动作和未来损失均能向 DIE 传梯度，硬128 packing误差为0，VLA参数哈希不变。F01是一个训练窗口的算子验收，不能当作全部窗口的数值等价证明。150个窗口的身份/时间对齐另行全量审计；未来目标与实际未来动作不进入部署输入。

## 配对闭环：主要结果

| 固定开发任务 | 完整模型 | A 动作监督 | B 动作＋未来监督 |
|---|---:|---:|---:|
| 0：汤罐与番茄酱放入篮子 | 10/10 | 10/10 | 10/10 |
| 3：碗放入底层抽屉并关上 | 9/10 | 7/10 | 7/10 |
| 5：书放入收纳架后隔间 | 10/10 | 9/10 | 10/10 |
| **合计** | **29/30（96.67%）** | **26/30（86.67%）** | **27/30（90.00%）** |

90/90条记录完整，0次策略异常、0次基础设施异常、0个未完成尝试；8次未成功均到达520步上限，保留在分母中。A/B共同成功25、共同失败2、仅A成功1、仅B成功2。任务3有一得一失；净增加的1次成功来自任务5。[独立审计](../results/g1_future_long_v1/closed_loop/independent_review.json)复算通过，30组三臂初始观测哈希一致，所有记录的硬剪枝数量与原始位置顺序正确。

B−A为 **+3.33个百分点**。按任务分层、配对初态重采样的探索性95%区间为 **[−6.67，+13.33]个百分点**（2000次，seed1517），跨过零。它仅描述这3个任务、1个训练seed的固定开发面板，不支持总体显著性或跨任务泛化结论。两组仍低于完整模型。

## 离线动作与 token 诊断

在相同的60个验证窗口上比较，两组均为真实硬剪枝；动作误差在归一化8×7动作上计算。

| 指标 | A | B |
|---|---:|---:|
| 相对完整教师 L1 均值 | 0.0252724 | 0.0256168 |
| 相对完整教师 L1 p95 | 0.0630333 | 0.0639796 |
| 相对示范动作 L1 均值 | 0.0259997 | 0.0264140 |
| 最佳更新 | 100 | 100 |

B的平均teacher L1增加0.0003444（约1.36%）；19个窗口改善、38个变差、3个相同。验证集同时用于选模，以上是选模后的描述性比较。

同一60个观测上，A/B集合平均交集占128个保留token的 **98.23%**，Jaccard为96.54%，仅3/60窗口集合完全相同，平均替换2.27个token。这里没有将两条闭环轨迹中的不同观测直接对比。

B的未来MSE从1.02185降到0.371886；将视觉读出置零后为0.971408，倒序实际动作后为0.372021。预测头使用了视觉输入，但该诊断对动作顺序不敏感；这些是训练后读出干预，不能等同于独立训练消融，更不能把未来误差下降当作控制收益。集合几乎相同与闭环仅少量差异是已观察到的事实，尚不能确定收益较小的原因。

## 时间跨度与隔离

379条episode固定分为265 train / 55 validation / 59 test；选取30条train和20条validation，各取早/中/晚3个合法窗口。划分无交集，150个窗口均为同轨迹合法h8区间，无补尾帧；所有轨迹长度足够，本次无短轨迹需排除。test没有窗口、图像解码或模型评测；全量清点仅使用元数据与压缩内容身份。

选中轨迹长162–458步，中位数260；8步占控制转移数的中位比例约3.09%。当前到未来的末端位移均值3.17cm、中位2.39cm、p95为8.45cm；两视角RGB MAE分别为0.02273/0.06974（0–1尺度）。因此目标确有数值变化，但8步仍是局部时间跨度；这些量不能证明跨越语义子任务，更不能把跨度当作当前结果的已证实原因。详见 [时间对齐审计](Long_G1F_数据协议与时间对齐审计.md)。
