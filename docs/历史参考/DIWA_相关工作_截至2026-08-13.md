# CTI-VLA 相关工作与未来 WAM 路线调研

归档说明：本文于 2026-10-12 从 F:/DIWA 复制，仅保存截至 2026-08-13 的历史调研；旧称谓和 WAM 规划不作为独立 CTI-VLA 项目的当前范围。最新方案及新增近邻对比见 [研究方案](F:/CTI-VLA/docs/研究方案.md) 和 [方法解释](F:/CTI-VLA/docs/工作对比与方法解释.md)。

> 调研截止：2026-08-13。论文状态以 arXiv/OpenReview 页面为准；除特别注明外，“已发表/接收”不等同于仅有 arXiv 预印本。本文用于 CTI-VLA 的 related work、baseline 选择和后续 WAM 立项，不把尚未完成的实验写成论文结论。

## 0. 结论先行

VLA token pruning 已经是一个竞争密集的方向。仅提出一个 MLP scorer、使用 attention/gradient，或泛称“action-aware pruning”，不足以形成清晰贡献。CTI-VLA 应把边界锁定为：

1. 在冻结 OpenVLA-OFT 的条件下，用 matched token intervention 定义 **conditional counterfactual decision influence**；
2. 用 action-level regret 和逐样本 candidate gate 检验 token selection 是否保持决策等价；
3. 只有在 packed token 的真实延迟和 worst-case gate 同时通过后，才声称 sparse acceleration。

未来若转向 WAM，最稳妥的切入点不是立刻复刻 14B 像素视频扩散，而是沿 **训练期世界建模、测试期轻量策略** 的路线，把 DIE 从“视觉 token 对动作的影响”扩展为“latent world state 对多步动作/未来子目标的反事实影响”。Fast-WAM 明确支持这条路线。

### 1.1 必须区分的三个概念

- **saliency proxy**：attention、gradient magnitude、token norm、instruction similarity、trajectory gating。它们可作 baseline，但不能自动称为 causal/decision influence。
- **learned selector**：LightVLA、CogVLA 等通过训练选择器或路由器学习压缩；必须说明是否改变 backbone、是否需要 post-training。
- **counterfactual decision influence**：CTI 的候选定义。对同一 observation、instruction、proprio、噪声和 matched baseline，只替换一个 token/subset，再比较 normalized action chunk 的 Huber 距离；这是模型内部的条件反事实量，不是对真实物理环境的 Pearl 因果效应。

### 1.2 CTI-VLA 最小公平 baseline 集合

**主表（同一 OpenVLA-OFT checkpoint、同一 LIBERO manifest、同一 control loop）**：

1. Dense/full retention；
2. Random/uniform（含 camera/frame 分层 uniform）；
3. attention-to-action；
4. gradient magnitude / integrated-gradient proxy；
5. token norm；
6. **LightVLA**；
7. **SpecPrune-VLA**；
8. **ADP**；
9. **VLA-Pruner**；
10. **SP-VLA**（若能保持相同 action head 和控制协议）。

CogVLA、EfficientVLA 和 SAFE-Pruner 更适合放在“架构级/扩展 baseline”表，除非成功复现它们的训练和 kernel。每个 baseline 必须同时报告：full-token candidate coverage、top-1/top-8 recall、action regret、success、retention、dense/masked-full/packed 三种 latency、peak allocated/reserved memory。只有 mask 而不改变 sequence shape，不得计入 wall-clock speedup。

## 2. WAM 相关工作

这里的 WAM（World Action Model）不是简单的 VLA token pruning：它把动作与“动作将如何改变视觉世界”的显式建模联系起来。各论文的关键差别是：像素视频还是 latent dynamics、是否训练时联合视频、测试时是否真的生成未来、action head 是否深。

| 工作 | 状态/链接 | 核心范式 | 对 CTI 的启示 | 后续对比 |
|---|---|---|---|---|
| **DreamZero / World Action Models are Zero-shot Policies** | arXiv:2602.15922，2026-02-19 提交。 [原文](https://arxiv.org/abs/2602.15922) | 基于预训练视频扩散 backbone，联合建模视频与动作；报告跨任务/跨 embodiment 泛化，14B 模型约 7Hz closed-loop | “世界动态”可成为比单纯语义 VLA 更强的物理先验，但计算和数据规模远超当前 CTI | WAM 路线的像素视频扩散代表；不作为第一阶段实现目标 |
| **LingBot-VA / Causal World Modeling for Robot Control** | arXiv:2601.21998 v2，2026-03-22 修订；[原文](https://arxiv.org/abs/2601.21998)，[代码](https://github.com/robbyant/lingbot-va) | autoregressive diffusion；共享 vision/action latent space 的 Mixture-of-Transformers；closed-loop rollout 和 asynchronous inference | 显式 action-conditioned frame prediction、闭环反馈、异步执行是完整 WAM 系统所需模块 | 作为 video+action joint modeling 的强对比，不与 CTI 当前 frozen-OFT 结果混合 |
| **Fast-WAM: Do World Action Models Need Test-time Future Imagination?** | arXiv:2603.16666 v2，2026-03-23 修订。 [原文](https://arxiv.org/abs/2603.16666)，[项目页](https://yuantianyuan01.github.io/FastWAM/) | 训练时保留 video co-training，测试时跳过 future prediction；比较 imagine-then-execute 与去掉测试时想象的变体；报告约 190ms、LIBERO/RoboTwin/真实任务竞争结果 | 最重要的路线判断：WAM 的收益可能主要来自训练期 world representation，而不是测试期反复视频去噪 | **未来 WAM 第一基线/设计依据**；应优先复现其 ablation：video co-training on/off × test-time imagination on/off |
| **LaWAM: Latent World Action Models for Efficient Dynamics-Aware Robot Policies** | arXiv:2606.15768，2026-06-14 提交。 [原文](https://arxiv.org/abs/2606.15768) | 在预训练 vision foundation model latent space 训练 latent action model，预测未来 observation features/latent visual subgoals，不重建像素视频；报告 LIBERO 98.6%、RoboTwin 91.22%、约 187ms | 与 CTI 的 latent abstraction 最自然衔接：未来目标可以是 compact latent，而不是整帧视频 | **未来 WAM 重点对比**；可作为 CTI→WAM 的最短技术路径 |
| **Faster-WAM: Do World Action Models Need Deep Action Modules?** | arXiv:2608.02365，2026-08-03 提交，当前为 v1 预印本。 [原文](https://arxiv.org/abs/2608.02365) | Dock of Transformer (DoT)：30 层视频 Transformer 作为 representation hub，单层 action head 通过跨层 K/V docking + RoPE realignment 接入；报告 66.5ms，约为 Fast-WAM 3.2× | WAM 的瓶颈不只在 token 数，也在 action module 深度；未来必须单独消融 action-head depth、cross-layer KV 和视频 backbone | 作为 Fast-WAM 后续的架构级 latency baseline；不能与 Fast-WAM 混名 |

## 3. 从 CTI-VLA 进入 WAM：建议的最小路线

### W0：把当前 CTI-VLA 做成可信的 VLA 论文

- 冻结 OpenVLA-OFT action head 和 normalization contract；
- 完成 candidate-pool、ranking/calibration、hard-case、full-retention、packed speedup 五类 gate；
- 把 LightVLA / SpecPrune-VLA / ADP / VLA-Pruner 与 attention/gradient/random 做同协议对比；
- Stage-A gate 未通过前，不引入未来视频或新的 world model。

### W1：增加训练期 latent dynamics，不改部署协议

在视觉 token 或其 pooled latent 上新增 action-conditioned dynamics head：

\[
\hat z_{t+h}=F_\phi(z_t,a_{t:t+h-1}),\qquad
\mathcal L_{dyn}=\sum_h\|\hat z_{t+h}-z_{t+h}\|_1.
\]

优先预测 object/contact/event/progress latent 或 VFM feature，不先重建 RGB。动作策略仍由 OpenVLA-OFT 产生，动态头只作为辅助训练与诊断，防止一次性共同学习导致 influence target 漂移。

### W2：将 DIE 扩展为 latent-world decision influence

对 token/latent slot 做 matched intervention，比较多步 action chunk、latent subgoal 和 progress 的变化：

\[
\Delta_i^{world}=\alpha D_A+\beta D_{latent}+\gamma D_{progress}.
\]

仍需 source-index、content-permutation、joint-permutation、episode-disjoint manifest 和逐样本 worst-case gate。这里的“world influence”仍是 declared model-internal intervention，不应写成真实环境因果发现。

### W3：优先复现 Fast-WAM/LaWAM 的轻量部署原则

- 训练期保留 video/dynamics co-training；
- 测试期先采用 Fast-WAM 式 no-future-imagination；
- 若 latent subgoal 能稳定降低 action regret，再尝试 LaWAM 式 compact future latent；
- 只有在 latent 路线有效且有足够算力时，才考虑像素视频扩散或完整 imagine-then-execute。

### W4：架构和系统消融

至少包括：video co-training on/off、test-time imagination on/off、pixel vs latent future、action-head depth、cross-layer KV/docking、packed token count、控制频率与异步 pipeline。WAM 的核心指标除 success 外，还必须有 future latent prediction error、action regret、real-time latency、control frequency、peak memory 和 OOD physical generalization。

## 4. 当前论文叙述的安全边界

可以说：

> CTI-VLA learns a conditional counterfactual decision-influence estimator for decision-equivalent visual-token abstraction on OpenVLA-OFT.

不要说：

- 首次提出 action-aware/token pruning；已有 SpecPrune-VLA、ADP、VLA-Pruner 等近邻；
- 已经是完整 WAM；当前没有 action-conditioned future world rollout；
- influence 是真实物理世界的 Pearl causal effect；当前是模型内部、声明 intervention 下的 estimand；
- mask 后必然有加速；必须有 packed kernel 和端到端测量；
- 平均 regret 通过就代表安全；当前项目明确要求逐样本 worst-case gate。

## 5. 最终阅读和复现优先级

**第一优先级（CTI 主线）**：LightVLA → SpecPrune-VLA → ADP → VLA-Pruner → SP-VLA。

**第二优先级（系统/架构扩展）**：SAFE-Pruner → CogVLA → EfficientVLA。

**第三优先级（WAM 路线）**：Fast-WAM → LaWAM → DreamZero → LingBot-VA → Faster-WAM；其中 Fast-WAM 决定“训练期世界建模、测试期是否想象”的路线，LaWAM 决定 latent future 是否能替代像素预测，Faster-WAM 提醒我们控制 action module 深度和跨层接口的系统成本。
