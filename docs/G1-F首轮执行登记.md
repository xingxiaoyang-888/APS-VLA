# G1-F 首轮执行登记

2026-10-14。下文保留运行前登记的设置。执行更新：**F01 已通过，A/B 各 100 次更新已完成，闭环进行中；尚无未来监督收益结论**。用户本轮明确授权替换研究主线；旧 G1 no-go 原样保留，G1R 候选诊断、逐 token 标注与分阶段重评分暂缓。实际结果见 [实验进度](实验进度.md)，不以执行后的结果修改下文设置。

问题仅为：在相同动作监督和训练条件下，未来视觉状态监督是否改善硬剪枝后的控制表现。A 是 CTI-DIE 的 ACL 式匹配动作监督对照，不等同于原生 ACL 复现；B 只增加训练期未来头。两组动作损失均为 0.5×完整教师动作 L1＋0.5×真实示范动作 L1，使用 checkpoint 的动作归一化。

机器可读冻结设置见 [g1_future_v1.json](../configs/experiments/g1_future_v1.json)。两组整个 VLA 冻结，软门控梯度经过冻结 VLA；DIE 输入仅当前双视角视觉、指令和 proprio。每相机软预算 64，温度 2→0.1；部署一次硬 Top-k 共 128 tokens，一次共享 packed VLA 前向。

未来窗口为同轨迹 obs[t]、实际动作[t:t+8]、obs[t+8]，要求 t+8<N，不填充尾部。官方 no-op 重放在执行前跳过空动作，此处跨度表示重放后的 8 次保留控制步，不冒充原始时间戳。以现有 diagnostic30 条 train 轨迹各取首/中/末合法起点；有效 validation 每任务按 seed517 取 2 条轨迹、每条 3 个合法起点。原划分、整轨迹曝光排除与 test 封存不变。

冻结未来视觉编码是现有 OFT 的 projected tokens；每视角 16×16 网格池化为 2×2，固定 seed917 高斯投影至每格 64 维、逐格无参数 LayerNorm，共 512 维。它是通用视觉表征，尚不能称作语义状态或任务相关状态。预测头读取门控后的同类当前表示和 8×7 实际示范动作，结构为 568→256→512、SiLU；B 加 0.1×逐维 MSE，A 权重为 0。未来目标 detach，未来图像与动作都不进入 DIE 或策略输入，部署删除预测头。

训练 seed17、相同 DIE 初始化和样本顺序，100 次 AdamW 更新，微批 1、累积 8、学习率 1e-4、weight decay 0.01、梯度裁剪 1。第 0/25/50/75/100 次更新评估真实硬剪枝 validation teacher L1；两组均选择最小值，平局选更早步。不存在 λ 搜索，不按未来损失选 B。未来误差、零视觉输入/动作打乱读出只作诊断，不据此扩模块。

先单独执行真实 L40 验收：时间索引与目标隔离、动作/未来损失分别对 DIE 的非零有限梯度、VLA 无参数梯度及参数不变、dense 可微路径与已验收教师一致、每相机 64 个唯一原位置及硬 packing 一致。任一失败先修复，不能自动开始训练。完整前反向的显存和耗时实测后再放行固定训练，不以“参数冻结”声称训练廉价。

训练后在已有独立开发初态的任务 0/3/5 各 10 个状态上配对运行 A/B、dense 与 uniform128；报告逐任务成功、配对差异及失败，不使用 test。硬动作误差报告均值、尾部、逐任务/阶段；完整延迟从原始 observation 到 CPU 动作，包含预处理、视觉、DIE、packing、VLA 与后处理。缓存、完整教师、前反向、选模、验收和失败重跑均记成本。首轮以相同更新数作因果控制，额外计算如实报告；相同累计计算预算控制仅在值得扩展时另行登记。

只有开发闭环出现 B 相对 A 的收益趋势才扩 seeds/预算；单 seed、30 配对开发状态不足以支持正式论文结论。无收益则检查时间对齐、门控梯度、视觉依赖与优化情况并报告，不继续加头或扩大旧标签。
