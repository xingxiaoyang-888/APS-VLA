# 正式主实验数据协议（formal_main_v2）

此协议用于四套件完整 train 池；旧 Spatial/Long 小规模实验与产物保留。尚未把任何正式主实验训练或闭环结果记为完成。

- `libero_spatial` 继承 302/64/66 episode 划分，排除已登记工程曝光的 1 条 validation，实际有效 validation 为 63 条。
- `libero_10` 继承 265/55/59 episode 划分。先前 90/60 窗口只是历史小规模面板，正式训练使用完整 train episode 池。
- Object/Goal 在模型结果产生前，以 episode 内容哈希去重，再使用 seed20261016、逐任务70/15/15及既有最大欠额整数分配规则。重复记录仅保留按 shard/index 排序的首个 locator，并登记全部别名；不允许同一内容进入多个 split。真实数量以固定 revision 的资产元数据和实际库存为准。

数据固定为 `openvla/modified_libero_rlds@6ce6aaaaabdbe590b1eef5cd29c0d33f14a08551`。构建前校验 metadata、每 shard 的字节数及 SHA256，再验证 TFRecord CRC。库存仅解析 protobuf 的长度、指令、边界标志及压缩内容哈希；不做 JPEG 解码、不创建 action/state 数组，也不构造 test 窗口。训练缓存生产者须只完整解码命中的 train/validation 记录，并调用 runtime 窗口校验。

长度 N 的有效轨迹允许起点 `0..N-9`：当前观测 `obs[t]`、真实动作 `actions[t:t+8]`、未来观测 `obs[t+8]`。no-op 过滤已发生在上游再生成过程中，h8 表示保留的八个控制步。末尾没有额外执行后观测，故不填充尾部。检测到中途 terminal/restart/end 时整条库存验证失败，不静默使用终止后的数据。

train 收录每个合法起点，不预选40k等子集。validation 每有效 episode 取首、中、末合法起点并去重；仅1/2合法起点时保留实际1/2，不重抽轨迹。`phase` 为合法起点范围的三等分位置标签；`selection_positions` 记录验证窗口代表的首/中/末位置，二者均不宣称语义子任务阶段。短轨迹、隔离轨迹与逐 task/phase 数量写入清单摘要。

API 位于 `src/cti_vla/data/formal_windows.py`：`load_formal_protocol`、`load_formal_windows`、`validate_formal_window`。清单含可索引 `windows`、完整 `train_window_ids` 和 `validation_window_ids`；每行有 window/episode/task/split/locator/time interval。loader 精确重生成窗口池，拒绝重新签名后的删减子集。`normalize_demo_actions` 直接复用既有 OFT 原生纯算子：使用相应套件固定模型统计，不重新拟合；未来投影和缓存张量由训练模块负责。

初态使用官方 LIBERO commit `8f1084e3132a39270c3a13ebe37270a43ece2a01` 的 `.pruned_init`。每任务50个状态，以旧 seed417、taskname SHA seeded shuffle 分成10开发/40封存。Spatial10任务与 Long原3任务的旧开发行和库存逐项相等；Long新增7任务、Object/Goal全部10任务在新结果前按同规则固定。CPU构建器可读取官方矩阵来预划分并写封存文件，但开发 loader 仅打开 development.json；旧 init_states_test.json 未读取。正式 final 打开须通过部署模块的完整冻结实验矩阵与 root release 校验。

路径统一为 `configs/manifests/formal_main_v2/{suite}/`：数据 `protocol.json`、`windows.json`；初态 `initial_states/development.json`、`final_registry.json`（只有索引/哈希）、`sealed_final.json`、`inventory.json`。封存数值不用于当前开发、选模或观察效果。

CPU命令（源码 snapshot 时显式指定主项目根）：

```text
python scripts/data/build_formal_data.py --suite libero_10 --project-root <project>
python scripts/data/build_formal_initial_states.py --suite libero_10 --project-root <project>
```

`--data-directory` 可指定容量盘；服务器仅允许已登记的 `/ssdfs/datahome/u15016/XXY_CVPR/CTI-VLA/data` 与 `/share/home/u15016/XXY_CVPR/CTI-VLA/data`，输出留在主项目。协议/窗口/初态均拒绝覆盖已有不同冻结内容。
