# LIBERO-Long 64-token与完整推理延迟实验结论

2026-10-15。**本轮第一、二部分完成，停止新增作业；C只保留候选登记，test封存。**

未来监督在同预算下提高了这组Long开发闭环成功率：64-token的A/B三seed均值为77.78%/85.56%，B−A为+7.78个百分点，条件95%区间[+1.11,+15.56]。但B64相对A128成功率低2.22个百分点，而实测median仅降低3.28%；**未达到预登记的跨预算占优条件**，不能声称等效成功率下可进一步加速。

## 结论与停止

同预算未来辅助监督有正向开发闭环证据，64-token下增益点估计较大；更强压缩的总体折中优势仍未成立。当前结果既不支持继续扩规模或搜索，也不足以解释辅助监督的机制。
