## 1. 研究问题与边界

分别训练、验证和评测 LIBERO-Spatial、Object、Goal、Long（`libero_10`），各用对应官方基座与示范，方法和超参数相同。Long → Spatial → Object → Goal仅作准入优先级；不同预算、seed和已验收套件并行，不逐套件串行等待。

## 2. 固定训练与部署定义

A的损失为 `0.5 × dense教师动作L1 + 0.5 × 真实示范动作L1`，B保持该损失不变，增加 `0.1 × 未来视觉摘要MSE`。动作在对应基座的归一化空间计算。选择器DIE及条件编码沿用现有结构：视觉/语言维4096、proprio维8、隐藏维256、两相机各256原始tokens。VLA全部参数冻结，但允许软门控分支的梯度穿过VLA回到DIE；当前特征、教师动作与未来目标detach。

未来窗口固定为同轨迹 `obs[t] + executed_actions[t:t+8] → obs[t+8]`。以冻结OFT投影后的视觉tokens构造目标：每相机16×16网格池化到2×2，每格经seed917固定高斯投影4096→64（尺度1/√4096）和无参数LayerNorm（eps=1e-5），共512维。训练期头为 `Linear(568,256) → SiLU → Linear(256,512)`；输入仅门控后的当前视觉摘要512维和真实执行8×7动作。语言与当前归一化proprio进入DIE，不额外拼入未来头。

示范未来只代表该示范动作的后果，不作为剪枝策略所预测另一动作chunk的真实后果。部署接口不接受未来观测、执行动作或未来头，只读当前两视角、指令和proprio；一次硬Top-k、相机等额预算、统一packing、一次VLA前向。

均匀剪枝采用固定嵌套空间网格，坐标从0起：256预算行步长2/列步长1；128预算行2/列2；64预算行4/列2。各相机分别选128/64/32，按原相机优先、行优先顺序packing；无训练seed，不按结果平移或旋转网格。128规则继承G0均匀对照。

每个预算从头初始化，不复用100步pilot权重。同suite/budget/seed的A/B使用相同DIE初始化和样本顺序；新增头独立RNG，不扰动DIE、采样或A分支。按固定seed洗牌完整池并循环；5000×8=40000次窗口使用，必须报告实际唯一窗口数、完整/部分遍历次数与分任务使用量，不能写成40000独立样本。

每50更新及每个验证节点原子保存完整恢复状态：DIE、未来头、AdamW、Python/NumPy/CPU/CUDA RNG、样本游标、门控位置、验证历史和成本。每500步候选身份留存。恢复不能重新洗牌或重置优化器，失败重放计算计费；此保存频率属于工程设置，不改变训练或选模节点。

初始执行按500更新分段：同一对先A到500、再B到500，随后共同恢复至1000，依次到5000。这减少有界共享缓存被整条A训练挤出后B重算的成本；每组仍从同一初始化连续训练5000步，调度始终按5000、选模仍使用全部11个验证节点。每段加载、保存、失败或重放均计入实际GPU成本。不得将段末权重冒充已完成的正式部署checkpoint。
