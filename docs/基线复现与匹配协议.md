# 基线复现与匹配协议

2026-10-14。本文是**待实现接口与比较协议**，没有新增 GPU 实验或复现结果。来源、许可证、权重 metadata 与源码 SHA256 见 [readiness.json](../results/baselines/readiness.json)；实验总约束见 [完整实验计划](完整实验计划.md)。官方源码只读存于 `external/`，模型权重及训练 checkpoint 只在服务器保存。

**先固定比较类型。**“同 packing”指硬删除推理时共用相同 token 顺序、原位置、attention mask 和动作读取规则；ACL 的可微软门训练仍然保留当前集合的长度，不能声称训练干预与硬删除相同。

| 方法标识 | 保留内容 | 可以回答的问题 |
|---|---|---|
| `acl-native-k32/k64` | 作者视觉 scorer、投影前输入、每视角一次 Top-k、公开对应权重 | 作者方法在共同开发场景的原生表现；不证明训练数据或容量匹配 |
| `acl-matched-teacher` | CTI scorer/条件/集合面板/硬推理，仅改为动作一致性训练 | **同 packing 的监督方式对照**；名称明确是 ACL 式 matched 变体 |
| `acl-matched-teacher-gt`（扩展） | 上述 matched 设置，加作者 0.5 教师 + 0.5 GT 损失 | 额外演示动作监督的作用；不混入纯教师监督主对照 |
| `specprune-native` | 历史信息、早期及层内剪枝、作者控制器和 attention 实现 | 独立系统比较，完整记录作者执行协议 |
| `specprune-matched-system`（后续） | 统一基座/观测/初态/时域，保留时序及层内机制，改动逐项登记 | 匹配评测协议的系统比较；**不能称同 packing 或监督方式对照** |

ACL 固定 commit `40b7a7a17f2f5a15acab0564ba1e304bcf6d150d`；SpecPrune 固定 commit `8091adc4b574ce9008d49a1dc9a210f4eec314c1`。任何修复或移植另存 patch、源码 hash 和 adapter version，不覆盖原生身份。

**1．公共观测和输出接口。**以下是拟新增接口，不是现有可调用实现。

```text
ObservationKey = episode_id, step_index, sample_id, protocol_signature
FeatureBundle  = raw_visual[B,512,Dv], projected_visual[B,512,Dllm],
                 ConditionalTokenBatch, prompt_ids, prompt_mask,
                 input_version, model_revision, input_fingerprint
Prediction     = normalized_actions[B,8,7], SelectionTrace, CostTrace
```

一次视觉编码提供同顺序的 raw/projected 特征：主视角原索引 `0..255`，腕部 `256..511`。条件使用现有 [ConditionalTokenBatch](../src/cti_vla/selection/conditional.py)：冻结词嵌入及语言 mask、归一化 proprio、camera/patch ID、有效掩码；条件编码模块属于可训练小网络。所有源特征 detached，并转换为可供 autograd 保存的普通 tensor，不能把 inference tensor 直接塞入 student 图。

共同硬推理采用总预算 `256/128/64`、每视角等额，分阶段 `512→256→128→64`，每阶段按当前 S 重评分。输出必须按原索引升序排列，不能按重要性重排。原 RoPE 位置是 `BOS=0、视觉=i+1、proprio=513`，语言及动作尾部保留完整序列的位置；物理数组偏移随 K 缩短。动作头沿用 [OFTPackedPrefixAdapter](../src/cti_vla/models/oft_adapter.py) 的 next-token shifted 56-token span，不另写一套切片。按 K 与 prompt 长度分桶；不以 padding 假装真实压缩。对应 [packing 契约](../src/cti_vla/models/abstraction/packing.py)。

**2．ACL 最小接入。**原生 scorer 读取投影前视觉特征，默认没有显式语言/proprio 条件；原生硬剪枝已经保留原位置。依据：[scorer 输入及 Top-k](https://github.com/du-owen/VLA-ACL/blob/40b7a7a17f2f5a15acab0564ba1e304bcf6d150d/src/openvla-oft/prismatic/models/patch_scorer.py#L11)、[原位置构建](https://github.com/du-owen/VLA-ACL/blob/40b7a7a17f2f5a15acab0564ba1e304bcf6d150d/src/openvla-oft/prismatic/extern/hf/modeling_prismatic.py#L496)。

原生接口只需 `acl_select(raw_visual, k_per_view) → original_indices`，先限定原生推理 B=1，再比较作者动作路径与共同硬 packing 的一致性。公开 Spatial 权重只覆盖每视角 K32/K64，即总数 64/128；总数 256 若另训或跨预算使用，要单独声明，不能假定已有对应权重。作者原生并列分数行为也要记录，matched 统一使用低原索引优先。

Matched 主版本固定如下，避免把容量、条件和监督同时改变：

1. 复用与 CTI 相同的 `ConditionalInfluenceEstimator` 配置、初始化种子、语言/proprio、动态 S 摘要，以及相同 `obs-S` 训练记录。scorer 输入仍是 detached projected features；raw features 只用于作者式软门，不增加 scorer 容量。
2. 每个训练 S 对应下一阶段预算：`512→256、256→128、128→64`，每视角独立 soft Top-k。保留作者投影前黑图特征门控 `sX + sqrt(1-s²)b` 及其 detached 黑图系数，随后经过冻结 projector。当前 S 的补集物理删除，S 内软门保持其 slot/原位置；不把黑图替换悄悄改成投影后均值替换。[作者门控与梯度路径](https://github.com/du-owen/VLA-ACL/blob/40b7a7a17f2f5a15acab0564ba1e304bcf6d150d/src/openvla-oft/prismatic/training/scorer_train_utils.py#L68)。
3. 新建独立 `FrozenDifferentiablePolicy.forward(projected_S, original_indices, prompt, proprio)`：共享 packing/action slice 规则，但允许对输入特征求导；所有 VLA/projector/head 参数保持 `eval` 和 `requires_grad=False`。**不修改现有 CTI teacher 的 no_grad 边界。**完整教师动作依旧无梯度、相同完整观测与条件；主损失为归一化 8×7 动作对完整教师的 mean L1。
4. 原生 `0.5 teacher + 0.5 GT` 只用于明确命名的扩展；GT 必须来自同训练观测、同 checkpoint 归一化与已核验的动作分块/轨迹末端规则。纯教师 matched 不需要引入 GT。依据：[作者损失默认值](https://github.com/du-owen/VLA-ACL/blob/40b7a7a17f2f5a15acab0564ba1e304bcf6d150d/src/openvla-oft/vla-scripts/train_scorer.py#L93)。
5. 推理直接复用现有 `staged_topk` 与硬 packing。软门、黑图特征、教师前向均不进入部署。ACL matched 的输出是排序 logit，不套 CTI 标签 RMS，也不把它解释为已校准的删除代价。

有效 batch、记录遍历次数、选模频率和搜索次数按完整实验计划登记；温度调度等 ACL 特有参数在开发前固定。另计 teacher forward、student forward/backward、checkpointing 重算、验证、缓存与总 GPU 时，不以相同步数代替相同训练成本。共享教师缓存同时报告实际增量与独立运行所需成本，不能把后运行方法继承的教师计算记为免费。

**3．SpecPrune 必须保留层内与时序接口。**拟采用 `reset(trial_id)`、`predict(observation, history, profile) → actions, next_history, trace`，由统一 runner 负责真实 `env.step`。history 至少包含前帧、已执行动作、前次重要 token、episode/inference 索引和层置信度；每个初态 trial 强制清空，不跨任务、方法或 seed 复用。

该方法首先处理完整输入，再在 LLM 层中改变序列长度。其 `cache_position` 同时追踪原位置，不能直接换成 CTI 的物理长度索引。每层 trace 保存 `original_indices、视觉数量、完整序列长度、position_ids、mask shape`；保护所有非视觉 token，按该层真实布局验证动作读取。作者源码：[强制 manual attention](https://github.com/alexwhz-sjtu/SpecPrune-VLA/blob/8091adc4b574ce9008d49a1dc9a210f4eec314c1/openvla-oft/prismatic/extern/hf/modeling_llama.py#L761)、[层内序列裁剪](https://github.com/alexwhz-sjtu/SpecPrune-VLA/blob/8091adc4b574ce9008d49a1dc9a210f4eec314c1/openvla-oft/prismatic/extern/hf/modeling_llama.py#L1143)、[原生预算调度](https://github.com/alexwhz-sjtu/SpecPrune-VLA/blob/8091adc4b574ce9008d49a1dc9a210f4eec314c1/openvla-oft/experiments/robot/spec_prune_constants.py#L23)。

首次接入先解决四项可核验差异：

- [GPU4 覆盖](https://github.com/alexwhz-sjtu/SpecPrune-VLA/blob/8091adc4b574ce9008d49a1dc9a210f4eec314c1/openvla-oft/experiments/robot/libero/run_libero_eval.py#L7)改为遵守调度器分配；变更只在 adapter。
- [历史 attention 固定 text 长度 34](https://github.com/alexwhz-sjtu/SpecPrune-VLA/blob/8091adc4b574ce9008d49a1dc9a210f4eec314c1/openvla-oft/experiments/robot/spec_prune_vla.py#L87)需核对 proprio 和可变 prompt 边界；修正后属于有记录的移植版本。
- [原生控制器](https://github.com/alexwhz-sjtu/SpecPrune-VLA/blob/8091adc4b574ce9008d49a1dc9a210f4eec314c1/openvla-oft/experiments/robot/libero/run_libero_eval.py#L435)在前 9 个 acting steps 不执行 env.step，之后还可能清空 action queue。先核验 warm-start/真实步数；原生 controller 与共同固定 8 步执行协议分别记录。修复后的运行不得写成“未改动原生复现”。
- 初次动态裁剪层 10 早于 importance 更新层 14；核对零分并列行为、禁用剪枝时的 dense parity，并保留作者设置的原始证据。

原生会使用不等额、逐层变化的 token 预算，也需要 attention maps；即使最后 K=128，也不等同于 CTI 从第一层开始仅处理 128。共同系统比较固定同一权重、预处理、开发初态、随机种子和环境时域；若调整 controller、attention 或预算，注明变体。报告逐层 token 数、每个真实控制步的调用数和完整延迟；分别画等延迟与等 token 曲线。作者 [CUDA 计时起点](https://github.com/alexwhz-sjtu/SpecPrune-VLA/blob/8091adc4b574ce9008d49a1dc9a210f4eec314c1/openvla-oft/experiments/robot/openvla_utils.py#L849)不含前置图像/相似度处理及后续历史提取，不能直接填入共同端到端延迟列。

**4．权重不可变 overlay。**overlay 是只复制小型配置/代码、引用服务器原权重的独立加载目录；本任务不创建它。

1. 原始 HF snapshot 按现有 [asset manifest](../configs/assets/openvla_oft_libero_spatial.json)逐文件验证、保持只读。每种 baseline 使用独立环境和进程，避免多个同名 `prismatic` editable 包相互覆盖。
2. overlay 单独复制 `config/auto_map、processor/tokenizer、统计文件与 remote-code .py`；权重分片及 action/proprio head 只引用已核验的只读原文件。禁止对原 snapshot 建可写配置链接；训练输出不得位于 snapshot/overlay 内。
3. 作者的 `update_auto_map/check_model_logic_mismatch` 只能指向 overlay。依据：[ACL 写入入口](https://github.com/du-owen/VLA-ACL/blob/40b7a7a17f2f5a15acab0564ba1e304bcf6d150d/src/openvla-oft/vla-scripts/train_scorer.py#L239)、[SpecPrune 复制行为](https://github.com/alexwhz-sjtu/SpecPrune-VLA/blob/8091adc4b574ce9008d49a1dc9a210f4eec314c1/openvla-oft/experiments/robot/openvla_utils.py#L160)。HF cache/modules cache 单独设置在两者之外，并启用离线加载。
4. 保存 `base_revision/base_manifest_hash、resolved_weight_paths+hash、overlay_file_hashes、source_commit、patch_hash、runtime_lock`；原资产校验和 overlay 校验分开，不能通过改写原 asset manifest 使差异消失。运行前后确认原权重及元数据不变。本地仅保存这些清单、日志和非权重结果。

**5．训练 split 与验收守卫。**所有 matched 训练先加载 [冻结 protocol](../configs/manifests/spatial_g0g1_v1/protocol.json)，每条记录必须由 `require_sample(episode_id, step_index, split="train")` 返回权威身份，再校验 raw episode 内容 hash、shard/record、sample ID；不能信任调用方填写的 split。当前训练是 302 轨迹/906 观测，matched ACL 使用与 CTI 相同的 G2 obs-S 清单，不能退回读取作者整个 RLDS `train`。验证只能用有效 63/189；曝光轨迹、test66/198 不参与训练、尺度拟合或选模。90/12 清单只供 G1，不代替正式训练集。

公开 ACL scorer 的训练成员未登记，无法证明遵守我们的 episode 隔离，故只作为原生权重证据。新增采样或增加每轨迹帧数必须冻结新 manifest，让全部 matched 方法同时使用；不能绕过当前三阶段样本守卫。

进入开发 GPU 验证前，CPU 行为测试至少覆盖：split/exposure 拒绝；双相机索引及原位置；相同输入的 native/common hard packing；student scorer 有梯度且 VLA 参数无梯度；soft 输入梯度不中断；SpecPrune history reset、层内非视觉 token 保留和真实 env.step 计数；overlay 原目录不发生写入。真实动作 parity、显存和速度仍需后续在服务器验证，文档本身不构成通过。
