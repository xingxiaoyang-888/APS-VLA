## 本轮发现并修复的问题

- checkpoint verifier 的包入口无条件导入 `preflight.py -> torch`，导致无 torch 基础环境无法验收权重；改为白名单惰性导入并增加主动封锁 torch import 的 subprocess 测试。
- 离线 conda create 因 cache 缺少 repodata/`_libgcc_mutex` 失败；失败后目标目录为空，改用隔离 venv。
- torch 2.2.0 与镜像默认 NumPy 2.2.6 存在 `_ARRAY_API` ABI 风险；固定 NumPy 1.26.4 后最小 CUDA smoke 通过。
- `huggingface-hub==0.23.0` 与 `diffusers==0.30.3` 的 `>=0.23.2` 约束冲突；改为精确 `0.23.4`，不使用 `--no-deps` 绕过 resolver。
- 上游 processor/runtime 需要 `draccus` 等轻量包；已冻结这些依赖，同时保持 TensorFlow/RLDS 训练栈隔离。
