当前离线证据表明：未来预测头学到了可降低表征误差的映射，但尚未显示对硬 token 选择或动作一致性的额外收益。这里只审阅已有输出，不推断尚未完成的闭环结果，不修改方法或实验门禁。

**已核实的事实。** A/B 均为 seed17、100 updates，共用初始选择器、训练顺序和冻结 VLA；各自在同一 60 个验证窗口上按 hard128 teacher L1 选模，均选中 update100。

| 最终验证指标 | A | B |
|---|---:|---:|
| 归一化 teacher L1 | 0.0297141054 | 0.0297940155 |
| 归一化示范动作 L1 | 0.0302903444 | 0.0303234886 |

B−A teacher L1 为 +0.0000799101（相对 +0.269%）；60 窗中 B 更低/相同/更高为 21/17/22。保留集合的平均交集占 128 个 token 的 99.1927%，平均仅 1.033 个保留 token 不同，17 窗完全相同；这不是 Jaccard，后者为 98.4070%。两个方法均较共同初始化的 0.10019357 明显降低离线 teacher L1，但这不等于相对固定基线的闭环收益。

B 的未来 MSE 从 1.031437 降至 0.307897；最终置零当前视觉输入为 0.968437，倒序执行动作输入为 0.308232（仅增加 0.000335）。这些未来读出是在软门控当前视觉上计算的，与 hard128 动作评测并列，不能当作 hard128 未来预测效果。

**可能解释，尚未验证。** 未来头可通过自身参数学习当前视觉到短期未来表征的映射，而无需明显改变 token 的排序边界；这与集合高度重合相容。相邻时刻的外观连续性、2×2 池化和固定投影也可能使当前视觉已包含较多预测信息。现有记录没有分离头学习、选择器变化及动作监督的贡献，不能确认上述机制，也不能断言辅助梯度被动作损失压制。

置零视觉后误差升高说明这个读出对视觉输入敏感；置零同时是分布外干预，不证明 B 保留了更有控制价值的 token。倒序动作影响很小也不能证明模型忽略动作：同一段动作倒序仍保留其取值集合，且窗口内动作可能相近；当前没有足以分离动作贡献的匹配对照。

**结论边界。** 只有一个种子和 100 次更新，且这 60 窗同时用于选模；微小均值差异不能证明统计等价、稳定劣化或泛化优势。F01 的非零辅助梯度证明路径可训练，未来 MSE 下降证明读出误差下降，两者都不能替代硬选择的闭环收益。若已登记的配对闭环最终未显示 B 的收益，建议按原方案停止扩种子和训练规模；不因未来损失下降自动调参或扩展。目前不提前假设闭环胜负。
