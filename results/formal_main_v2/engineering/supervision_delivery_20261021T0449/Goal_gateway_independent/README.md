# Goal remaining-five 原子网关独立审查

本包独立审核 root 编写的网关；作者本人编写的五pair计划未在本审计中自审，它们由另一代理审查。最终审核范围为源码与 CPU。全部测试只在服务器私有目录写入，未查询或提交 Slurm，未写 canonical/P/state/Git，未运行或捏造新科学试验。

固定 v3 网关绑定最终20文件runtime和exact scope。原302正/383拒逐条重建；独立新增重复碎片、同pair/跨模式、双pending、持久化/BaseException、原ACK、不重复release、完整sacct确认与成本检查。原v2缺少两处pair_key被实际runtime函数拒绝，证据保留；v3恰仅增加两字段，实际 Native.dispatch_proof 经最终 entry.validate_dispatch 和 consumer.validate_job 对全部五scope闭合。

CPU admission 测试在内存中使用明确标注的根/独审/actual-P结构fixture，只验证真实函数的字段/来源/接口守卫。这些fixture不落到生产路径，不代表真实根采用、actual P、工程验收或GPU成功。已有原始控制器和注册作业状态仅通过保存的真实日志重建。

root仍须另行完成计划/runtime独审、精确发布、真实根收据和prepared invocation、actual P、全五pair保守存储容量及每次原子提交前真实容量/lease对账。正常作业仅一个attempt，不自动重试。未来完整原始日志consumer和独立终审不在本包中预记成功。
